Resource array starts with six 0xffffffffffffffff values; each syscall fills a slot ONLY if it returns a valid descriptor.
close_fds closes descriptors 3 through 29 inclusive AFTER scheduling calls. Calls use worker threads, which means textual case order does not prove completion order.
NOTE: file begins with #define __NR_ioctl 54 (when absent) and #define __NR_openat 295.
Verified kernel tables: i386: ioctl 54, openat 295; x86_64: ioctl 16, openat 257; x86_64 number 54 = setsockopt, 295 = preadv.
Therefore, compile original generated C as 32-bit x86 for ABI fidelity. A 64-bit compile is NOT equivalent. Check -m32 availability before attempting.
The original C uses 16 thread slots, 10 call cases, per-call wait up to 50ms, a final wait of up to 100ms, and outer process timeout 5000ms.
16*128 KiB=2048 KiB declared thread stack sizes if all 16 slots get created; this is an upper bound on requested thread stack sizes, not physical RSS.
10*50ms=500ms sum of per-call timeouts (upper bound on sum when each waits fully); actual calls overlap, and this does not predict real elapsed time.
5000ms / 10ms = 500 outer polling intervals in a fully blocked case; condition checking and scheduling introduce timing differences.
